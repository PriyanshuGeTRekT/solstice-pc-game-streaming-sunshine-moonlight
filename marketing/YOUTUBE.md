# Solstice — YouTube upload kit

Everything needed to post the launch video and the Short. Files are in `marketing/out/`:

| File | What it is |
|---|---|
| `solstice-youtube.mp4` | Main video, 1920×1080, 30 fps, 1:18, H.264 + AAC |
| `solstice-short.mp4` | YouTube Short, 1080×1920, 30 fps, 0:26 |
| `thumbnail.png` | Custom thumbnail, 1280×720 |

The music is original and was synthesised for these videos (`music.py`), so there is no Content ID claim. All screens come from the apps' demo mode, so no real PC name, address or game library appears.

To add narration, record a WAV and mix it over the music:

```powershell
ffmpeg -i out\solstice-youtube.mp4 -i voice.wav -filter_complex "[0:a]volume=0.35[m];[m][1:a]amix=inputs=2:duration=first[a]" -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k out\solstice-youtube-voice.mp4
```
